حساب همکار، کیف پول، قیمت سطحی و API خرید اکانت.

== Description ==

افزونه روی ووکامرس و در صورت وجود، روی جدول موجودی aimarket-accounts می‌نشیند.
موجودی را کپی نمی‌کند. قیمت عمده را از سطح همکار حساب می‌کند و موقع خرید،
کیف پول را با یک UPDATE شرطی کم می‌کند تا موجودی منفی نشود.

مستندات فارسی در صفحهٔ «مستندات API همکاری در فروش» و فایل docs/api-fa.html است.
مشخصات OpenAPI در openapi/openapi.yaml است.
